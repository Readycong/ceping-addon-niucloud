# 爱测评 · 设计规范（Design Guidelines）

| 项 | 内容 |
|---|---|
| 文档版本 | v2.2（与 PRD v2.2、原型 v2.2 同步） |
| 更新日期 | 2026-10-14 |
| 适用范围 | 小程序全端 UI（介绍页 / 答题页 / 结果页 / 海报 / 首页 / 分类 / 历史）、运营素材 |
| 风格关键词 | **大气 · 高端 · 全直角 · 编辑风（editorial）** |

> 本文档是「直角高端风」视觉改造后的唯一权威规范。所有新页面、新组件、运营素材必须遵循；与旧稿冲突处以本文档为准。

---

## 1. 设计原则

1. **直角即态度**：全站零圆角（包括按钮、卡片、弹层、头像容器、进度条，甚至"圆形"元素一律方角化）。直角带来印刷品的秩序感与高级感，是本次风格的**第一识别符号**。
2. **字号大半档**：标题类字号整体比常规小程序大 30–50%，制造"海报感"；正文保持可读性下限 13px。
3. **深色舞台 + 浮层内容**：全局背景是深色舞台渐变，页面内容如杂志版面浮在其上；首屏即有高级氛围，无需图片兜底。
4. **轻描边、重投影**：卡片不靠描边区分层级，靠**柔和投影 + 留白**；仅主题包（如 office-comic）刻意用硬描边制造风格反差。
5. **图片即质感**：封面与头区一律使用写实摄影图（§5），禁止插画与 AI 感素材。

## 2. Design Tokens

### 2.1 全局色彩（浅色基础层）

| Token | 值 | 用途 |
|---|---|---|
| `--app` | `#f6f7fb` | 页面底色（内容区背景） |
| `--ink` | `#1c2233` | 主文字（近黑蓝墨色，不用纯黑） |
| `--sub` | `#8a90a0` | 次要文字 / 说明 |
| `--line` | `#e8eaf2` | 分隔线 / 输入描边 |
| `--brand` | `#3b5bdb` | 品牌靛蓝（导航高亮、主行动色） |
| `--brand-soft` | `#eef1fe` | 品牌浅底（选中态、标签底） |

### 2.2 舞台背景（原型展示壳 & 运营主视觉底）

```css
background: radial-gradient(120% 110% at 50% 0%, #3c4257 0%, #232733 48%, #101318 100%);
```

- 用于：原型展示壳背景、分享头图底、运营海报外框；
- 小程序内页面主体使用 `--app`，不直接用舞台背景（保证内容区清爽）。

### 2.3 字体与字号阶梯

正文字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif`；主题包衬线字体：`"Songti SC", "STSong", serif`（`.serif`）。

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| 结果主标题 | **34px / 900** | 结果报告页结果名 |
| 介绍页主标题 | **31px / 900** | 介绍页测评名（衬线体） |
| 历史页标题 | **25px / 900** | 「我的测评记录」 |
| 题干 | **24px / 800** | 答题页问题（行高 1.6） |
| 关键数字 | **21px / 800** | 介绍页 meta（题数/分钟/人次）、仪表盘总分 |
| 分类大卡标题 | **20px / 900** | 分类 Tab 大卡 |
| 列表条目标题 | **17px / 800** | 历史记录条目 |
| 卡片标题 | **15.5–17px / 800** | 信息流 / 热门卡 |
| 选项文字 | **16.5px / 400**（选中 700） | 答题选项；对偶二选一变体 15px/800 |
| 正文辅助 | **13–13.5px** | 副标题、时间、meta 小字 |
| 标签 / Dock 文字 | **11.5–12.5px / 600** | 标签 chip、底部导航 |
| 底部导航图标 | **25px** | Dock 图标（选中上浮 2px 并放大 1.1） |

### 2.4 直角规则（硬约束）

- **一切 `border-radius: 0`**。搜索关键词 `radius`、`rounded`、`circle` 均不允许出现非 0 值；
- 原"圆形"语义元素（头像、徽标、进度环）改用**方形容器 + 内容居中**表达；进度环可保留圆环线形，但外框容器必须直角；
- 主题包中确需装饰性图形（如 chat-bubble 的对话尾巴）用 `transform: rotate(45deg)` 的正方形实现，不用圆角。

### 2.5 投影分层（elevation）

| 层级 | 投影 | 用途 |
|---|---|---|
| E1 卡片 | `0 3px 14px rgba(25,35,70,.06)` | 列表条目、小卡 |
| E2 面板 | `0 6px 22px rgba(20,30,60,.07)` | 题卡、介绍卡 |
| E3 浮层 | `0 14px 36px rgba(15,20,40,.2)` | 悬浮 Dock、弹层 |
| E4 微件 | `0 3px 12px rgba(0,0,0,.09)` | 返回按钮等小组件 |

### 2.6 间距与布局

- 页面左右安全边距：**16px**；卡片内边距：**18–30px**（越大越高级，优先大值）；
- 底部悬浮 Dock 高 68px，距底 **16px**、左右 **16px**；页面内容 `padding-bottom: 122px` 预留 Dock 空间；
- 区块间距：标题区 22px 起，列表项间 12px。

## 3. 组件规范

### 3.1 悬浮玻璃 Dock（底部导航）

```css
#tabbar{
  position:absolute; bottom:16px; left:16px; right:16px; height:68px;
  background:rgba(255,255,255,.94);
  backdrop-filter:blur(16px); -webkit-backdrop-filter:blur(16px);
  border:1px solid rgba(255,255,255,.65); border-radius:0;
  box-shadow:0 14px 36px rgba(15,20,40,.2);
}
```

- 未选中：`#9aa0b2` / 600；选中：`--brand` / 800，图标 `translateY(-2px) scale(1.1)`；
- 进入介绍页 / 答题页等沉浸页时 Dock 隐藏（`.hidden`）。

### 3.2 卡片

- 信息流卡：头图区（主视觉图 §5）+ 信息区（标题 15.5–17px + meta 13px）；
- 历史条目：左侧 **6px 主题色竖条** + 标题 17px + meta 13.5px + 标签 chip（11.5px，底 `#f1f3f8`）；
- 分类大卡：2 列网格，主题色 `linear-gradient(135deg, pri2, pri)` 渐变底、白字、右上角测评数徽标。

### 3.3 按钮

- 主按钮：`background:var(--pri); color:var(--card)`，**直角**，加粗，高 ≥ 48px，字号 16px+；
- 幽灵按钮：透明底 + `2px solid var(--line)` 描边 + `--sub` 文字；
- 返回按钮：40×40 白底直角方块，`‹` 符号 21px，投影 E4。

### 3.4 答题选项（.opt）

```css
.opt{ border:2px solid var(--line); background:transparent; font-size:16.5px;
      padding:17px 18px; border-radius:0; transition:all .18s; }
.opt.sel{ border-color:var(--pri);
          background:color-mix(in srgb, var(--pri) 12%, var(--card)); font-weight:700; }
```

- 选中态：主题色描边 + 12% 主题色底 + 字重 700；选项 key 徽标（A/B/C/D）选中国底色反转。

### 3.5 弹层 / 表单

- 遮罩：`rgba(10,14,26,.55)`；弹层面板直角、E3 投影、内边距 ≥ 20px；
- 输入框：直角、`1px solid var(--line)`、聚焦切 `--brand`；
- Toast：深色直角条（`#2a3042` 白字），不出现在弹层内。

### 3.6 图标规范（iconfont）

- 图标库：**Remix Icon 4.5（空心线性 `-line` 全套）**，开发期 CDN `https://registry.npmmirror.com/remixicon/4.5.0/files/fonts/remixicon.css`（国内稳定），**上线前转自托管**字体文件；
- 底部导航：首页 `ri-home-5-line`、分类 `ri-layout-grid-line`、历史 `ri-history-line`；选中态只变品牌色 + 上浮放大，不切换实心版本，保持全站空心；
- 分类图标（金刚区与分类 Tab 大卡共用一套语义映射）：人格认知 `ri-emotion-line`、情感关系 `ri-heart-line`、职场成长 `ri-briefcase-line`、社交人际 `ri-group-line`、情绪状态 `ri-sun-cloudy-line`、生活消费 `ri-shopping-bag-line`、兴趣审美 `ri-palette-line`、玄学脑洞 `ri-magic-line`；金刚区图标着分类主题色，分类大卡图标白色；
- 边界：主题包装饰元素（介绍页水印、封面角标 emoji）属主题内容不算功能图标，保留原样；
- 新增图标必须取自同一库 `-line` 系列，禁止 emoji 与线性图标混用于同类场景。

## 4. 主题包 Token 示例（差异化基线）

每个测评绑定一个主题包，主题包通过 CSS 变量整体换肤（`--bg/--bg2/--card/--pri/--pri2/--acc/--tx/--sub/--line/--serif`）。已定稿 8 个：

| 主题包 | 气质 | 关键差异 |
|---|---|---|
| persona-archive | 藏青 × 鎏金档案 | 深底金字、衬线体、金色细线纹样 |
| love-letter | 情书粉 | 内描边 `inset 0 0 0 1px #ffd9e3` |
| office-comic | 办公漫画 | 黄底、3px 硬描边 + 硬投影（唯一直角阴影例外风格） |
| chat-bubble | 对话气泡绿 | 方形对话尾巴（rotate 45°） |
| wave-healing | 治愈水蓝 | 低饱和浅底 |
| zine-collage | 杂志拼贴米红 | 米纸底 + 红黑撞色 |
| gallery-aesthetic | 画廊紫灰 | 灰紫高级灰阶 |
| tarot-night | 塔罗深夜 | 深紫金、径向渐变头区 |

> 新增主题包必须复用同一组变量名，禁止另起 token。

## 5. 图像规范（主视觉图 / hero image）

> 完整产品定义见 PRD §6.10（FR-19）。本节是设计与素材生产视角的操作规范。

### 5.1 基本要求

- **写实摄影**，高质感、无 AI 感：真实光影、自然色彩、生活抓拍感；
- 每个测评一张，16:9 横图（`landscape_16_9`，成图 ≥ 1368px 宽），三处复用：信息流封面、热门卡、介绍页头区。

### 5.2 Prompt 公式

```
{具象生活场景的英文摄影描述} + , realistic photography, 35mm film, natural light, candid, editorial style, muted tones, no text, no watermark
```

- **场景**：与测评主题强关联的具象隐喻（例：#7 契合度 → `two coffee cups on a windowsill with a rainy city view outside`；#8 心态段位 → `a hiker silhouette on a mountain ridge at sunrise`；#12 九型人格 → `nine antique brass keys arranged on dark linen fabric`）；
- **后缀**：固定不变，负责质感统一与去 AI 感（35mm 胶片、自然光、抓拍、编辑风、低饱和）。

### 5.3 素材红线

1. 禁止插画 / 卡通 / 3D 渲染 / 油画化；
2. 禁止赛博朋克霓虹、过饱和、HDR 油腻感；
3. 图中不得出现可读文字、logo、水印；
4. 避免可识别人脸特写（剪影、背影、手部、静物优先）；
5. 避免 AI 常见破绽构图（六指、镜像文字、物理不合理阴影）——成图后人工筛检。

### 5.4 版面合成规则

| 位置 | 合成 |
|---|---|
| 信息流封面 | 图铺满头图区；上/下渐变压暗层（`rgba(12,16,28,.18→0→.5)`）；`NO.xxx` 白字左上、主题 emoji 白底角标右下 |
| 热门卡 | 图铺满；下部深压暗（至 `.75`）；`TOP n` 与标题白字压在暗部 |
| 介绍页头区 | 图铺满；渐变至主题卡底色 `var(--card)`，标题/标签落在渐变过渡区 |

- 层级：图片 z-index:0 / 压暗层 1 / 文字 2；
- 图片加载失败 → `onerror` 隐藏图片，露出主题渐变底（回退层），文字仍可读；
- 海报 Canvas 不引用远程图（防 CORS 污染 `toDataURL`）。

### 5.5 生产流程

1. 开发期：按 `COVERS` 映射表（原型 JS 内，50 条）经文生图 API 批量生成；
2. 筛检：按 §5.3 红线人工过筛，不合格换场景重生成；
3. 上线前：转存自有 OSS + CDN，接口改为按 test_id 下发图片 URL；后台可替换。
